# **App Name**: DTSSM Connect

## Core Features:

- User Authentication: Secure phone number OTP authentication using Firebase Authentication.
- Member Directory: Browse and search a directory of community members with privacy controls.
- Biodata Management: Create and manage biodata profiles for unmarried members with visibility settings.
- Admin Dashboard: Admin interface for approving members, managing events, and user data.
- Community Events: Share and view official community events with details and optional photos.
- Consent Workflow: Request and grant consent to view hidden profile details using SMS or in-app prompts.
- Profile Review Reminders: Quarterly SMS or in-app reminders for members to update their profile information.

## Style Guidelines:

- Primary color: Soft blue (#60A5FA) evoking trust and serenity, aligning with the community's harmonious atmosphere.
- Background color: Very light blue (#F0F9FF) for a clean, airy feel.
- Accent color: Emerald green (#34D399) for interactive elements, providing contrast.
- Headline font: 'Poppins', sans-serif, providing a modern, clean and easily readable style. Use 'PT Sans', sans-serif for body text, since the application will contain blocks of text more than one paragraph in length.
- Simple, elegant icons to match the minimalist design language.
- Card-based layout with rounded corners and soft shadows, optimized for mobile-first design.
- Subtle transitions and animations for a smooth user experience.
